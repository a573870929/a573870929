一、数据三层（实测）

· 高播放 1000+：标题带「宝妈做自媒体 / 自媒体新人 / 口播视频第X天」锚点。最高：7-22「宝妈做自媒体拍口播视频第八天 报喜了」5610 播放 / 379 赞 / 98 评论。

· 中上 1700-2650：痛点 / 认知类带自媒体锚点，如「自媒体新人不要纠结赞多赞少」1769 播 / 216 赞 / 198 评论（互动率极高）、「先完成再完美」2463。

· 低播放 129-235：泛情感 / 觉醒鸡汤无自媒体锚点，如「宝妈觉醒 一切向内求」129、「全职宝妈 不甘平庸」235。

二、关键结论

已验证铁律③（自媒体人视角）：锚定「宝妈做自媒体」身份 + 真实过程感 / 痛点 → 播放好；一旦滑向泛情感鸡汤 → 数据断崖。跟内容是否「深刻」无关。

三、行动清单（写稿前对照）

1. 隐藏低数据泛情感两条（每天 2-3 条清，别一天全干）。

2. 优化置顶：保留「第八天成绩」，加「数据差不放弃」或「新人别纠结赞多赞少」，再加「先完成再完美」。

3. 标题公式：宝妈做自媒体 / 自媒体新人 + 痛点 / 认知 / 第X天。

4. 抖音权重健康，近期重点发力，日更 1 条；视频号同步发已验证爆款。

5. 反面案例：7-26「做自媒体到底该信谁？」仅 46 播——标题平问句、缺强情绪 / 利益点 / 第X天过程感、封面利益点弱、未用已验证爆款结构。

四、提醒

此规律是「宝妈做自媒体」身份锚点下的数据，不是泛成长号规律。每条抖音写前先问：标题里有没有「宝妈做自媒体 / 第X天」这类锚点？
